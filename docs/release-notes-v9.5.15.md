# Codex Account Manager Next v9.5.15

Release name: 0909v4

## Highlights

- 统一新用户默认值：中文、列表、系统主题、7 天剩余额度菜单栏、⌘U，以及 Astra / Low / 标准速度；升级保留用户保存的偏好和关闭选择。
- 卡片额度数字使用固定字号，不再按单张卡片缩小。工作台、单账号与菜单栏按账号身份匹配共享占用，排除调度的账号也能显示维护状态。
- 继承 0909v3 的准备即占位、进程状态、暖号互斥和同一日期问题日志。成功处理重置事件后，即使官方额度仍为 100%，也不重复立即暖号；调用期间的新事件继续保留。
- 新版调度预检在资格门禁通过后消费优先标记；指定账号不被排序替换。结果按实际结束状态收取，进程结束与产物验收分开记录。
- 中英文 README 改为使用场景、安装口令与四个调用模板，配套生成封面和原生演示截图，技术说明移至独立文档。

## Runtime acceptance

本次在已有调用结束后预约全部 9 个托管账号，未创建假 Hub 任务或真实模型任务。Hub 重启前后 249 个原任务 ID 完全相同；原有 10 项接单开关逐项恢复。

Next 在原路径覆盖安装，实际运行二进制与最终候选一致。24 项捕获设置、9 个账号的参与状态、优先偏好、模型参数及顺序一致。原生界面确认全部 9 个账号显示维护占用并阻止终端入口；释放后 7 个原可调度账号恢复空闲入口，2 个原排除账号继续沿用原有映射保护。全部维护预约已释放。

## Runtime boundaries

- 完整官方 5 小时/7 天自然重置周期仍需到时观察。源码和离线测试不能替代自然窗口的真实暖号验收。
- 本轮未发起真实任务派单、账号切换、登录或通知测试，不以开关开启证明通知送达。
- 旧 CLI、原生交互终端和直接绕过 Skill 的 Hub API 不自动登记；共享互斥只覆盖已接入协议的入口。
- Windows 源码保留，本轮未开发或验证 Windows。Intel 构建不属于本轮验证范围。
