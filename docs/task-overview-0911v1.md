# 任务概览 · 0911v2

相较 0911v1，补齐归档中性状态并与完整应用整合。

从“窗口 > 任务概览”主动打开原生浮动面板。面板显示待处理、运行中和最近结束数量，展开后最多6条任务；点击后使用既有定位入口打开原任务。

任务数据复用现有 TaskBoard 与 Codex 实时快照。实时状态遵循45秒新鲜度边界，断联和陈旧记录不会被描述为正在运行。第三方已有记录可以展示，但不由此推断其 CLI 已建立实时连接。归档只表示整理动作，不计为完成；明确的运行结果优先于归档分类。

窗口重复打开时复用同一实例，关闭或退出时释放内容并取消订阅。可见面板复用现有刷新计时器，不新增轮询源。标题单行截断，不展示任务正文、工作目录或凭据，不持久化消息。

完整 macOS 构建、26组纯自检和独立 presentation fixture 通过。真实窗口定位、Escape焦点和点击跳转仍需在桌面验收。
