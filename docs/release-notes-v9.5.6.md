# Codex Account Manager Next v9.5.6

Release name: 0907v2

## Highlights

- 相比 0907v1，主界面新增「列表 / 卡片」切换并保存选择，默认仍为垂直列表。卡片网格使用柔和渐变、大字 5 小时额度及次级 7 天额度，随窗口宽度调整列数；两种视图共用账号顺序与全部原有功能。
- 点「编辑」后，账号右上角出现三条横杠拖动手柄。列表支持上下移动，卡片支持跨列移动，180ms 过渡遵循系统“减少动态效果”；拖动只改显示草稿，成功松手才调用原有保存路径一次。区域外松手或 Esc 取消，账号集合或顺序变化后拒绝过期拖动，右键及辅助功能仍可上移/下移。
- 列表使用紧凑对齐行：身份在左、5 小时和 7 天额度上下排列居中、模型与操作在右顶对齐、红色重置提醒在左下；终端入口为纯图标，保留说明和辅助功能标签，分组间距适度放松。
- 顶部统计可展开；账号完整名称、更新时刻、官方累计、会员资料和历史暖号可点“详情”。临近会员到期、额度不足、读取失败与未知状态继续留在主行。
- 关键异常字标红加重，日期和普通状态保持中性。仅省去与额度栏官方重置时间相同的暖号日期；不同的预约、失败原因和未知时间不被省略。
- 保留刷新、暖号、参与调度、优先偏好、模型设置、终端、监控、Desktop 切换及编辑功能，不改变原有业务回调与安全检查。

## Design reference

列表参考 [Apple 官方 Mac 机型比较](https://www.apple.com.cn/mac/compare/) 的同类信息对齐与一致列结构；卡片参考 [Quota Float](https://github.com/change-42-yhmm/quota-float) 的圆角渐变卡片、突出额度和次级重置信息。仅参考排版，不引入对方源码、悬浮球、Tauri 或新的依赖，仍使用原生 SwiftUI/AppKit。

- 对抗式复核覆盖旧布局默认值、功能与禁用条件保留、取消不落盘、排序期间账号变化、减少动态效果、长名称和异常信息不裁切，以及预览不写真实偏好。跨显示器和长时自动滚动仍属未验收范围。

## Runtime acceptance boundaries

- 本轮由主线程直接修改与复核，没有调用其他账号或子 Agent。
- 预览与测试只使用合成账号和隔离目录；未安装或替换正在运行的 Next，未操作真实账号、切号、真实暖号或飞书通知。
- 未修改、重启或部署 Hub。“优先派活”仍只保存偏好，当前 Hub 尚不消费此标记。
- 视口能显示的账号数取决于窗口尺寸、备注和异常长度；不以固定高度裁切异常。长截图保留完整滚动内容和主界面展开状态，不包含临时弹窗。
- 布局与顺序使用 Next 自有设置和原有保存路径；合成预览的排序不会写入真实用量累计偏好。未验证跨显示器拖动、长时间拖动边缘自动滚动或真实账号长时运行。
- 本次只推送源码，不创建标签或 GitHub Release。
