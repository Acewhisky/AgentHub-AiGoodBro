# 重置卡展示与排序 · 0911v3

相较 0911v2：首页改为真正跨供应商的账户序列，新增通用“固定第一位”设置，并统一卡片、列表与供应商页面的到期规则。

当前核对的 Grok 官方 billing 响应未包含重置卡数量和到期字段。生产解析保留 resetCards=nil，显示“重置卡信息暂不可用”；不会用额度恢复时间、账期截止或订阅有效期代替卡到期。此限制不代表账号一定没有卡。

选择一个账户固定第一位后，具有新鲜官方证据、且卡在未来72小时内到期的账户稳定排在其后；只有一个到期账户时，它就是第二位。多个到期账户保留原相对顺序。固定账户本身到期仍保持第一。公开代码不包含私人 Pro20 标识，本机选择保存在 Next 自己的设置中。

卡片和列表共用红框判断：0 < 到期时间 - 当前时间 <= 72小时，证据读取成功且不超过5分钟。过期、未来读取时间、读取失败和未知数据不参与到期优先。已过期卡不计入可用数量；已知有卡但缺到期时间时保留数量并显示“到期待确认”。

专业与极简首页都使用同一账户序列；供应商入口保留其完整操作。账号卡片预设固定卡片布局，其他布局允许列表/卡片切换。Codex 账号编辑时使用已保存顺序，拖动不改变置顶设置。

```sh
bash scripts/test-grok-reset-cards.sh
```

离线 fixture 已验证72小时、5分钟新鲜度、未知/已过期、多卡、跨时区、跨供应商置顶与排序，以及真实官方响应形状保持未知。WorkspacePreviewRenderer 另提供标为合成数据的跨平台布局。没有调用任何重置卡。
