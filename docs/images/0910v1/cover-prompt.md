## 内容与文字

受众是已经使用 Codex、想少盯重置消息和账号状态的人。新版本增加第三方公开重置公告提醒、账号参与调度时段，并修复独立终端入口。画面表达“看到公开消息，再检查自己账号”，不能暗示自动兑换额度、官方背书或所有账号已经重置。

## 风格与构图

明亮、克制的体素世界，所有主要元素由方块、规则立方颗粒与清晰网格几何构成。主标题是场景中央偏左真实存在的巨大方块招牌，字形面向观者、中文清晰可读，不是粘贴在游戏截图上的字幕。标题有奶油白侧壁，微小、柔和的投影，足够大的留白让手机缩略图仍能看清。

中央偏右是一座简洁的蓝色方块通知铃，与一个带小时刻度的方块时钟构成小型站点。细金黄路径从铃延伸到一个小小的抽象终端方块，终端上只有无字的几何光标，不画真实软件界面、账号、数字额度或发送成功状态。物件总数克制，避免堆满工具图标。标题约占画面宽度的三分之二，物件约占三分之一。人物可以完全省略。

下方次标题与说明位于同一块奶油白体素铭牌上，和主标题在空间中连接；铭牌不是普通信息卡片，不分成多块并列面板。阅读顺序为 CODEX NEXT → 中文次标题 → 简短功能说明 → 右侧铃与时钟。所有文字和主体距边缘保留至少 6% 安全区。

## 字体、色彩与材质

主标题使用厚实、干净、可读的方块字，字形不能过度像素化。中文使用结构准确的粗体字，以像素铭牌镶嵌字的方式融入物件。最大标题只有 NEXT 的 N 正面是朱红 #E74732，其他字母为钴蓝 #0256EE，侧壁奶油白。次标题与说明为蓝色。仅铭牌最下沿另有一条细红色线，不增加其他红色。

整体约 60% 浅天蓝 #B1D4F6 与干净奶油白 #FBF5EE，30% 饱和钴蓝，10% 克制点缀。红色只占全图约 3%，金黄路径细而不抢视线。不必增加绿色。材质是细腻哑光陶瓷般的积木，边缘清晰，干净日光与柔和环境阴影，有真实空间深度；无青色霓虹，无蓝紫科技渐变，无强烈泛黄。
