## 本次变化

- 工作台增加本机 CLI 图标与账号切换。Codex、Grok、Kimi、Claude Code、OpenCode Go、Gemini 以及明确配置的 GLM/Z.AI Coding Plan 各按自己的凭据和协议读取；MiMo 与 ZCode 原生订阅额度保留未接通提示。[覆盖范围](local-cli-accounts.md)
- 三个执行档位可修改名称、主模型、思考强度、是否使用子代理及其组合。标准档沿用已有设置，其他初始组合为 Sol High / Luna Max 子代理、Luna Max 直接执行。最终生效参数在启动前校验。
- 环境引导检查已有 Python 3.9+ 和 Codex CLI，支持准备配套 Skill 与可选 Hub。外部运行时不打进包；已有 Hub 和个人配置保留，含旧版脚本包装启动方式。
- 飞书正文可选择账号备注、额度、重置时间、重置卡数量和到期明细。默认简洁显示，Agent 与余额为可选项；不显示长任务编号。
- 账户卡保留每个账号自己的官方余额原值，绿色显示可用重置卡数量；币种和换算未被接口确认时不推算。
- 选中账号增加三次确认的重置卡入口。请求前重新核对账号、卡片、期限及共享占用，未知结果保留同一尝试。**本版未执行或测试重置流程。** [实现与边界](reset-credit-control.md)
- 修复参与时段“添加区间”后新增行被压缩不可见的问题，新增后滚动至末行，保存前仍是草稿。

## 健康与协作修复

有界读取覆盖本地缓存、CLI 响应和输出流；修复整数转换溢出、子进程及描述符清理、运行回执原子写入和过期回调。账号取消关联后释放对应刷新任务与缓存。活动记录保留运行中占用，并按最新完成时间保留有限历史。

CLI 的 plan / run / result 保存实际执行参数与退出回执。退出成功和业务验收分别记录；配置了子代理不表示它已经执行。本轮真实 CLI 工作者使用 Sol / Medium，自定义 Luna 组合未执行真实模型验证。
