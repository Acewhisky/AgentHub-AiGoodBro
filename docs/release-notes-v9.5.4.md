# 0905v4 · 重置后的暖号与飞书提醒

本地版本为 9.5.4 (16)，上一版为 0905v3 / 9.5.3 (15)。本轮没有安装、推送或发布安装包。

## 新增行为

自动化中心的飞书设置新增「额度重置提醒」和「获得 Reset 卡提醒」。两个选项默认关闭，需要先配置 Webhook 并开启飞书总开关。启用任一新提醒后，纯额度维护刷新改为约每分钟一次；关闭后恢复原来的 10 分钟或 30 分钟维护间隔。

额度提醒依据新鲜官方数据中的窗口变化或明显额度恢复，不把倒计时归零当成成功。Reset 卡提醒依据官方可用次数增加，消息包含新增次数和当前可用次数；不根据本地手工校正的历史计数发送，也不会兑换或使用 Reset 卡。

首次同步只建立基线。提醒按官方账号身份合并，忽略乱序响应、重复观察、未知字段恢复和不同额度桶之间的变化。长期离线后先重建基线，不补发历史消息。网络发送失败只记录脱敏错误，不反复重发同一事件。

## 暖号时机

保留官方重置时间后 8 秒的缓冲，再刷新官方额度并通过原有身份、参与调度、周额度和 Hub 空闲检查。到期刷新与暖号后确认使用纯额度读取，减少本地统计造成的等待。定时器遇到刷新、登录或账号操作重叠时，每 5 秒重新检查，避免直接丢失本次到期刷新；这一步不会发送暖号请求，原有检查仍须通过。Mac 需要保持运行、唤醒和联网；忙碌、失联或验证失败仍会阻止暖号。

## 验证范围

已完成独立目录的 macOS 构建与签名完整性检查，额度事件判定、飞书通知载荷、暖号策略及账号存储自测均通过，修改的 Swift 文件格式检查和差异空白检查通过。真实官方窗口变化、真实 Reset 卡到账、真实飞书送达、到期碰到忙碌操作的运行表现与运行中 UI 尚未验证。不能把源码自测当成真实消息已经送达。
