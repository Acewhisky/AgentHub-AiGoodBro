# 任务概览归档状态 · 0911v2

相较 0911v1，已完成与实时状态、窗口生命周期和完整构建的整合。

`kind == .done` 表示列表归属，`displayState == .archived` 或 archive 依据表示用户整理动作，两者都不是任务完成证据。仅有这些信息时显示中性的“已归档”，不计入最近结束数量。

明确的运行状态和 runner 结果仍优先采用；同一条任务有可靠完成、失败或中断记录时按该证据呈现。陈旧 running 记录不能让归档任务重新显示运行中。

纯测试覆盖仅归档、归档同时失败、归档配旧运行记录、明确完成、未知状态和既有完成/中断 fixture。当前测试及完整 macOS 自检通过；恢复旧归档映射的临时副本曾触发6条断言失败。该副本不进入产品。

没有为本次验证运行真实任务、切号、登录、发送通知或兑换重置卡。
