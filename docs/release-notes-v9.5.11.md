# Codex Account Manager Next v9.5.11

Release name: 0908v6

## Highlights

- 相比 0908v5，5 小时暖号、7 天暖号、低额度提醒、macOS 通知、飞书通知、额度重置提醒和 Reset 卡提醒默认开启。明确保存的关闭选择保留；新账号默认参与调度，既有退出选择保留。
- 新增四步使用引导，支持全部开启、跳过、保存进度、键盘导航和重新进入。引导说明暖号的额度消耗，并分别显示功能开关、macOS 权限与飞书配置状态。
- 系统通知默认开启，首次使用仍由用户授予系统权限。系统已拒绝通知时可直接进入通知设置；返回应用或重新进入通知页后读取当前状态。未配置飞书时保留开启偏好，并显示待配置。
- 相比 0908v4，低额度提醒可分别设置 5 小时与 7 天阈值；macOS 通知仅包含剩余额度百分比。维护启动参数暂停的功能会显示原因，临时覆盖不会被其他设置操作保存为永久偏好。
- 相比 0908v3，启动时取得单实例锁，构建前拒绝覆盖运行中的目标包。账号设置与额度更新共用事务和文件锁；状态文件丢失或损坏时保留现场，防止旧实例覆盖新状态。
- 调度同步保留退出账号的编号，重新加入时沿用原编号；刷新结果按实际成功保存的新快照计数，写入失败不再显示刷新成功。

## Validation

- 本机 macOS arm64 构建通过严格签名校验，版本为 `9.5.11 (25) / 0908v6`。
- 26 组自检和 75 项调度同步测试通过，覆盖默认值、明确关闭、维护覆盖、引导进度、单实例锁、状态事务和调度同步。
- 全量 Swift 格式、macOS 兼容性、全局内存风险检查及 5 项运行时 PNG 资源比对通过。
- 16 张使用合成账号的原生 SwiftUI 预览覆盖中英文与明暗主题。
- 已完成本机覆盖安装，并核对运行版本、二进制哈希与单实例。实际引导验证了七项全开、全部开启、跳过续看、安装后保留进度、键盘完成及完成后重新进入。
- 系统通知设置入口和授权后的状态回读已验证；通知配置状态与实际送达分别记录。

## Runtime acceptance boundaries

- 本次更新同步源码和说明，不创建 Git 标签、GitHub Release 或上传安装包。
- 实际通知横幅与飞书收件方送达未测试。自动化中心的部分界面验收受本机界面控制服务异常影响，未据此声称全部控件通过。
- 真实 5 小时和 7 天自然重置后的暖号仍需结合新鲜官方额度与请求时间验证，不能以开关开启或请求成功回执代替。
- 登录失效必须通过对应账号的官方登录流程恢复；额度耗尽与登录失效是不同状态。不会自动使用 Reset 卡或更换当前 Codex Desktop 身份。
