# AiGoodBro 9.6.0 (37) · 0913v1

相对 9.5.22 (36) / 0912v1，主要变化是将 Token Monitor 的原始统计引擎接入首页，并统一消息、头像与直接拖动的交互。

- 首页依次展示 Agent 导航、最新公开重置消息、Token 用量和已登录账号；平台子页移除重复的全局总量。
- 新增 Token Monitor 默认统计与原有自定义模式选择，保留工具、模型、日期、会话与项目维度。年度热图、趋势和明细可切换；日期提示合并已获取的重置公告。
- 最新消息保留北京时间、原文与中文翻译状态。预告不显示成已发放，翻译迟到或失败不会串到另一条公告或重发通知。
- 悬浮窗依据所选平台、账号和指标展示实际数据；来源失效时明确显示未知。设置预览与桌面窗口共用同一数据来源。
- 使用当前品牌资源，头像编辑结果接入实际账号；裁剪预览复用一次渲染，右键恢复默认执行实际恢复。
- 账号排序增加并发复核，保留隐藏账号的位置；导航与排序入口使用直接拖动手柄。
- 授权同步区分成功复制、内容相同和保留已有有效会话，防止旧副本覆盖较新的授权。服务端撤销或到期仍需要实际重新验证。
- OpenCode Go 额度接入上游原始读取器；限定选定账号，保留临时失败时的原生回退，并区分未授权、限流和未知额度。
- 固定统计依赖和 Node 运行时，构建检查完整来源清单、下载摘要、签后摘要与本架构运行。运行时不依赖开发机缓存。
- 移除未启用的 Antigravity OAuth 客户端常量并禁用对应授权入口；已有本地 Token 采集保持可用，不分发上游授权凭据。

本文件记录源码候选变化，不代表所有平台或真实消息渠道均已验收。构建、回归测试、原生界面操作和真实通知送达分别记录；本版未发布 GitHub Release 安装包，也没有执行真实账号切换或使用重置卡。系统翻译在 macOS 15+ 且语言能力可用时启用，旧系统保留原文及明确状态。

参见 [Token Monitor 集成说明](token-monitor-integration-0913v1.md) 与 [通知渠道说明](message-channels-0911v1.md)。
