# AiGoodBro 9.6.0 (43) · 0913v8

相对已安装的 0913v6，把个人窗口与重置卡收进消息左栏，右栏展示四条更早动态，中等窗口自动铺成多列，收起底部说明以减少空白。面板正文隐藏裸网址，详情保留可点击的来源入口，原始公告数据不变。主界面 Logo 隐藏链接至 aigoodbro.com，关于页补充官网、GitHub 和 AIHOT 参考鸣谢；AIHOT 作为呈现参考，本版未改用其 API 或配置飞书推送。补齐旧版 Swift 编译器要求的主线程隔离标注。

0913v7 为未安装的诊断候选，未发布；本版从已验证的 0913v6 继续。

相对 0913v5，重置看板改由原生 Layout 按父容器可用宽度排列，解决长公告导致错误竖排及窄窗口被内容撑宽的问题。宽窗口三列展示消息、日历与近期公告，中等窗口两列，小窗口纵排。账号排序的拖动区域与落点分开承接，增加可访问的行标识和位置菜单。

相对 0913v4，重置消息区新增北京时间公告日历、翻月、按日筛选、近期公告与原文详情，复用已验证的公开数据源，并保留历史范围和到账含义说明。关于页新增 Token Monitor、Tokscale、codexU、Codex-Manager、Codex Resets、Node.js 和使用者鸣谢，附对应项目链接。工作台取消 1280 点的内容宽度上限，宽屏与全屏使用可用宽度并保留 24 点边距。账号排序改用显式拖放方式，保留本地草稿、单次拖动标识、取消与保存并发检查，并支持辅助操作上下移动。

相对 0913v3，修复实机发现的账号排序首次打开为空，以及独立设置窗口缺少 Command-W 关闭快捷键的问题。排序弹窗现在随完整账号快照一次呈现，保存仍核对当前账号顺序，取消不写入。趋势图日期刻度随宽度抽样，大数使用短格式，刷新后保留日期范围。悬浮窗设置增加隐藏入口，可直接撤下桌面窗口。补齐原生编辑快捷键，账号搜索无结果时可一键清除筛选。

相对 0913v2，重做主窗口、平台账号页、设置、引导、菜单栏和悬浮窗的布局与操作层级。品牌与 Agent 导航固定在顶部，内容按重置消息、Token、已登录账号排列；账号常用操作直接显示，模型与调度按需展开。设置改为独立原生窗口，分外观、菜单栏、悬浮窗、自动化、工作台和关于六类。移除引导中的旧模式选择和菜单栏的任务展示入口，复用已有账号、额度、统计和调度服务。

相对 0913v1，本次修复安装后实机发现的问题：合法长公告不再阻断每日图表；未安装翻译语言包时先显示页内提示，由用户点击后下载；已核对的重置完成公告附带来源链接时也可直接显示准确译文。首页提前展示消息距今与北京时间，将个人额度说明折叠；Codex 页移除剩余的跨 Agent 用量区。

相对 9.5.22 (36) / 0912v1，主要变化是将 Token Monitor 的原始统计引擎接入首页，并统一消息、头像与直接拖动的交互。

- 首页依次展示 Agent 导航、最新公开重置消息、Token 用量和已登录账号；平台子页移除重复的全局总量。
- 新增 Token Monitor 默认统计与原有自定义模式选择，保留工具、模型、日期、会话与项目维度。年度热图、趋势和明细可切换；日期提示合并已获取的重置公告。
- 最新消息保留北京时间、原文与中文翻译状态。预告不显示成已发放，翻译迟到或失败不会串到另一条公告或重发通知。
- 悬浮窗依据所选平台、账号和指标展示实际数据；来源失效时明确显示未知。设置预览与桌面窗口共用同一数据来源。
- 使用当前品牌资源，头像编辑结果接入实际账号；裁剪预览复用一次渲染，右键恢复默认执行实际恢复。
- 导航管理和账号排序使用原生拖动列表，保存前增加并发复核，保留隐藏账号的位置；取消不写入顺序。主界面不再常驻拖动手柄。
- 授权同步区分成功复制、内容相同和保留已有有效会话，防止旧副本覆盖较新的授权。服务端撤销或到期仍需要实际重新验证。
- OpenCode Go 额度接入上游原始读取器；限定选定账号，保留临时失败时的原生回退，并区分未授权、限流和未知额度。
- 固定统计依赖和 Node 运行时，构建检查完整来源清单、下载摘要、签后摘要与本架构运行。运行时不依赖开发机缓存。
- 移除未启用的 Antigravity OAuth 客户端常量并禁用对应授权入口；已有本地 Token 采集保持可用，不分发上游授权凭据。

本文件记录源码候选变化，不代表所有平台或真实消息渠道均已验收。构建、回归测试、原生界面操作和真实通知送达分别记录；本版未发布 GitHub Release 安装包，也没有执行真实账号切换或使用重置卡。系统翻译在 macOS 15+ 且语言能力可用时启用，旧系统保留原文及明确状态。
