# 0909v3 / 9.5.14 (28)

2026-09-09 的本机候选阶段记录；以下改进现已合入 [0909v4](release-notes-v9.5.15.md)。相比 0909v2 / 9.5.13 (27)：

- 准备执行就可显示“在线·准备中”，实际启动后显示“在线·运行中”，进程结束与产物验收分别显示。
- 接入 Skill 共用的本地占用文件；暖号先预约账号，再确认 Hub 空闲，避免与使用协议的新调用同时占用同一账号。过期或不明状态继续阻止新调用。
- 成功暖号确认本次已处理的重置信号，修复额度仍显示 100% 时反复立即暖号的路径；请求期间新出现的重置信号继续保留。缺少官方窗口不再视为重置证据。
- 统计刷新与无关编辑分别控制；仍保护真实启动、登录和身份切换。优先派单说明对应新 Skill 的实际排序行为。
- 新增“运行问题日志”入口，与 Skill 追加同一本带 UTC、上海日期的问题日志；只记录固定原因、账号字母及不敏感标识，写入失败显示提示。

验证：26 组应用自检、21 项协作脚本回归、Python/Swift 文件锁及日志互通、格式、macOS 兼容、资源和签名检查通过。没有启动第二个日常实例或真实模型任务，没有切号、发送真实通知、重启 Hub、提交或推送。

边界：旧 CLI、原生交互式终端和直接绕过 Skill 的 Hub API 未自动登记；不能宣称所有入口已统一互斥。真实状态界面、自然暖号频率及完整 7 天周期仍待部署后验证。后续真实维护占位、设置恢复与覆盖安装见 0909v4 更新说明。
