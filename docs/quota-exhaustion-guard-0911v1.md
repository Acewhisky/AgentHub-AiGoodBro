# 额度耗尽保护 · 0911v2

相较 0911v1，候选已整合并通过完整 macOS 构建及纯自检。

任一已知订阅窗口耗尽后，手动或自动暖号都暂停。余额、重置点数、另一窗口的剩余额度，以及墙钟越过恢复时间，均不能单独重新授予暖号许可。

- 所选窗口缺失时拒绝；另一窗口不能替代。
- 官方额度读取失败、出现更新的失败记录或证据超过15分钟时拒绝。
- 异步 Hub 查询返回后，重新核对服务是否运行、请求是否仍有效、暖号是否开启、账号是否空闲，以及最新官方额度。
- 服务停止或取消后，迟到回调只清理自身资源，不发送新请求。
- 官方只读额度刷新独立运行；恢复暖号要求新的成功读取。
- 暖号历史最多保留20条，并拒绝时间倒退。

策略与实际入口在 CodexProfileStore 和 UsageStore 复用。26组原生纯自检包含暖号策略和账户存储，覆盖耗尽/缺失/陈旧/失败证据及停止后的异步续接。真实暖号、真实账号切换、官方完整恢复周期和 Hub 联动未在本轮执行。
