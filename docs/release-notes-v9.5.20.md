# AiGoodBro 9.5.20

Release name: 0911v2

Build: 34 · macOS · 2026-09-11

## 主要更新

相较 0911v1 / 9.5.19 (33)：

- 所有平台的账户进入同一首页序列，可固定常用账户第一位；官方证据新鲜且重置卡将在72小时内到期的账户随后排列并显示红框。列表和卡片使用同一规则；Grok 官方缺少卡字段时明确显示未知。
- 新增原生任务概览，区分运行、待输入、归档和完成，支持打开原任务；修复取消、超时与迟到回调的状态覆盖。
- 任务完成提醒接入现有实时快照，要求先运行后完成；额度变化和重置卡新增使用不同文案。自动化中心增加独立开启的 Telegram 与企业微信，凭据存入 Next 自己的 Keychain。
- 调度层保留取消意图及部分产物，核对 Hub 终态和进程存活。统一入口补齐 Codex 运行委托，WorkBuddy 明确传入指定模型、清除无关认证环境并限制输出；认证未知和仅存在回执不显示调用成功。
- 完成额度保护、模型菜单、余额精度和专业/极简布局候选的整合。

## 验证与运行边界

本版已通过完整 macOS 编译和 ad-hoc 签名校验、26组原生纯自检、89项调度离线回归、运行资源校验、Swift格式与全局内存风险门禁。消息组件及控制器使用假传输验证启停、目标变化、迟到回调和完成事件；Grok重置卡边界 fixture 通过，统一账户的列表/卡片与明暗主题合成界面已检查。

未执行真实 Desktop 切号、暖号、重置卡兑换或消息收件验证；没有为回归调用真实付费模型。Grok 统一受管计划仍未接通，保留应用内官方 CLI 入口。个人微信与公众号当前没有适配，ZCode 等供应商的订阅额度接口仍按覆盖说明显示未知。Windows 源码保留，未验证。
