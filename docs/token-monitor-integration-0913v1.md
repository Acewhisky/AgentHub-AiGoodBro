# Token Monitor 集成 · 0913v1

相对 0912v1 的单独图表接入，本版同时接入原始统计引擎、固定运行时、完整统计 JSON、来源选择和年度重置注记。原有自定义统计仍可切换使用。

| 部分 | 本版做法 |
|---|---|
| 上游 | [Javis603/token-monitor](https://github.com/Javis603/token-monitor)，v0.56.0，固定提交 `ef079b6fb494e1cfcb24736cfcf4d4e591222eaf`，MIT |
| 采集二进制 | [Javis603/tokscale](https://github.com/Javis603/tokscale)，固定提交 `8ef7aa98add33f5ff65b495cf30807ce89b78e69`；基于 [junhoyeo/tokscale](https://github.com/junhoyeo/tokscale) |
| 原生集成 | Swift 管理显式来源、取消、超时与缓存；JS 桥接调用原始采集器；两端使用同一份 JSON 契约 |
| 大型历史 | 统计采集预算 60 秒；额度查询保持独立预算。完整 JSON 最大 16 MiB，后台编码一次，界面复用该快照 |
| 统计来源 | 上游目录共 28 种，默认启用 26 种；设置中可逐项选择。MiMo Code 可能重复导入 Claude 记录，Qoder CN 为上游实验性读取器，因此沿用其默认关闭 |
| 多账号 | 分别读取登记的 Codex 目录；当前登录不证明全部历史记录属于这个账号，未确认的归属不填入账号列 |
| 额度读取 | Codex 和 OpenCode Go 接入上游原始读取逻辑。OpenCode Go 只读取选定配置目录中的既有 API 授权；不会借用浏览器 Cookie、另一个账号或后台刷新授权 |
| 授权适配 | 本产品未启用 Antigravity OAuth：移除上游自带的客户端常量，发现、授权和远程请求入口明确返回不支持；不从环境或已安装软件恢复它们。已有本地 Antigravity Token 记录仍由上游采集器读取 |
| 额度回退 | 临时无法启动引擎或连接失败时，可回退既有原生读取器并标明来源；身份变化、无效数据或绑定不符会直接拒绝，不能用另一份旧数据冒充成功 |
| 自定义模式 | 沿用原有自定义来源与统计方式，与上游模式分别计算，避免把同一批记录加两次 |
| 图表 | 使用原始 `usageCharts.js`；本地适配器提供中文、概览/趋势/明细切换、日期提示与重置公告注记 |
| 重置公告 | 公告时间显示北京时间；日历注记按统计时区。翻译保留原文和状态，系统能力不可用时不编造译文 |
| 费用 | 保留上游费用及覆盖状态；缺价格不等于免费，也不使已确认的 Token 日期变成未知 |
| 运行时 | App 内自带固定 Node.js 22.23.2 和经过校验的依赖；运行时不安装 npm 包、不启用上游 Hub/Electron、自同步或后台更新器 |

`Companion/TokenMonitorEngine/SOURCE.json` 是构建使用的版本、源码和依赖凭据。构建验证完整文件清单、锁文件、下载摘要与签名后的文件；缓存位于 Next 独立目录，制品清理不删除它。包外构建回执只供构建验收使用，已安装 App 不依赖回执、源码目录或下载缓存。

更新上游时，应在独立工作目录获取指定提交，保留原文件和许可证，检查桥接使用的入口与字段，再生成新的来源清单。必须通过真实 JS 输出到 Swift 解码、空值与部分覆盖、取消/超时、打包和目标架构运行检查后替换当前版本。直接把远端最新分支覆盖进正在运行的 App，会绕过这些兼容检查，因此更新以可审查的源码变更交付。

本版保留旧自定义入口，并不意味着上游能读取所有服务的订阅额度。Token 日志支持、额度接口支持和可执行 CLI 是三张不同的支持表；对应账号没有上游可绑定的数据时，继续使用原有适配器或显示不可用。网页公告也不能替代账号自身的官方额度数据。

采集器、统计数据结构和图表保持固定上游实现；上述授权适配记录在来源清单中，不能将整个源码树称为逐字未改。源码与资源均标明来源。完整上游许可证随引擎、图表与各依赖一同保留。
