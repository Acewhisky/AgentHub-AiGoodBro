# AiGoodBro 9.5.22 (36) / 0912v1

相对 9.5.21 (35) / 0911v3，本次 macOS 源码预览修复额度数据、公开重置消息、桌面切换和界面交互。不包含 GitHub 二进制 Release 或 Apple 公证包。

- 支持 CC Switch schema 16/18 的按日统计与夏令时边界；历史可读、累计不完整时分别显示，避免把未知累计或无记录的日期当成零。
- 公告保留事件时间、公开内容与原文入口，区分普通重置、重置卡公告及当前账号实际额度；各通知通道独立记录接受、失败或不确定状态，不补发历史消息。
- 公告与后台回调遵守主线程和生命周期边界；通知测试连点共用占用控制，保存失败如实显示。飞书对未返回的 Pro 5 小时窗口显示未知，不推断为不限额。企业微信指群机器人，个人微信未接入。
- 手动与自动切换共用最终身份、任务、额度、进程和回滚保护；终端退出须有进程组与回执共同证据，无法确认时保留占用。
- 修正本机 Hub 配置路径解析，支持 LaunchAgent 明确的 --config；Pro 20x 不再因配置文件读错而缺少账号映射。当前已是 Desktop 账号时，不重复切换自己。
- 区分永久刷新凭据失效与普通401；app-server 提前退出、初始化失败或缺响应时及时结束等待，不制造成功。设备码的官方有效期不作延长。
- 凭据读取锁按解析后的实际目录合并；身份已验证的会员账号读取使用文件凭据后端，并清除会串入其他认证来源的子进程环境变量。
- 窄窗减少卡片列数，长公告可展开；图表分别显示加载、未知、空数据、失败及重试。悬浮窗显示真实或未知数据，并统一显示、关闭、平台与编辑入口。
- 更新原生图标、工作台/账号呈现与开源图表资源；App 和 DMG 附带的调度脚本使用同一份受审来源。

功能入口保持可见；实际动作仍校验配置、权限与证据。升级保留已有账号、调度参与和关闭偏好。未知或不完整的证据不会成为放行理由。

## 验证范围

本次发布源码在 Apple Silicon macOS 完成仓库格式检查、整合构建、临时签名和运行资源检查，格式修正后的 31 项应用自测全部通过。构建输入在验证期间未变化；同一二进制已覆盖安装为 9.5.22 (36)，原有账号、当前选择及所核对的设置均保留。模块回归另覆盖统计日界、通知路由、消息投递、共享占用、终端进程、自动切换门禁、登录子进程和配置解析。

新安装应用的实际窗口读取与截图已确认按日消耗、公开公告内容和账号操作入口。本轮电脑控制曾在点击时中断，重启后截图恢复；本次实机已通过原生控件进入全屏，并以 ⌃⌘F 退出，卡片布局随窗口宽度调整后恢复，所检查的顶部截图未见额外黑边或文字重叠。设置弹层、拖动与其他设置操作仍需独立验证，离线渲染不替代这些交互。

本轮没有真实切换账号、使用重置卡或向飞书/企业微信/Telegram 发送测试消息。离线回归不等于真实消息送达或完整重置周期验证。跨独立凭据副本的刷新协调仍需后续验证，不能据此宣称登录失效已全部消除。Windows 保持原样，未做 Windows 验证。
