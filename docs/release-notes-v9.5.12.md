# Codex Account Manager Next v9.5.12

Release name: 0909v1

## Changes from 0908v6

- 修复满额度账号的官方 reset 随读取滑动、让暖号一直推迟的问题。根据上次成功暖号时间分别计算 5 小时和 7 天维护周期，保留 8 秒余量；官方 reset 到期刷新继续独立执行。
- 暖号失败后至少 5 分钟重新核验再重试；账号忙碌时保留计划，缺少映射只延后对应账号。失败重试不能跨过尚未恢复的耗尽周窗口。
- 两种暖号继续独立于参与调度、套餐名称与旧会员日期。周额度仍可用时移除旧的 5% 暂停线；官方认证、身份、新鲜额度及 Hub 空闲检查仍生效。
- 退出调度支持同一已核实身份的多个 Hub 目录，保留原编号；加入时有目录歧义仍拒绝。同步反馈、暖号状态及中英文说明与实际行为一致。

## Validation

- macOS arm64 `9.5.12 (26) / 0909v1` 完成构建和严格签名校验，已在本机原路径覆盖运行并核对单实例。
- 26 组应用自检、76 项调度同步测试通过，新增覆盖冷账号滑动 reset、失败冷却、耗尽周窗口保护、缺失成功标志、同刻失败证据及同一身份多个 Hub 目录退出。
- 已观察到两个冷账号自动最小请求成功，官方 5 小时 reset 在后续读取中保持稳定；另一个已退出调度的账号按维护周期自动请求成功。

## Remaining runtime boundaries

- 完整 7 天自然周期仍待观察；请求成功与官方出现新窗口分别验收，不能以满额度或开关开启代替证据。
- 忙碌、身份未知、认证失败或额度耗尽时继续复核，实际请求仍受官方限制。电脑睡眠、离线或应用未运行时不能准点维护。
- 本轮未测试真实通知送达、登录或 Desktop 切换；未重启 Hub、创建标签、推送、发布安装包、制作 DMG 或执行 notarization。
