# 多账号调度 Skill 0910v1

此包用于 Codex Account Manager Next 的账号预检、共享占用、任务跟进与问题记录。相对 0909v4，新增参与时间窗检查、原生终端占用识别和 Hub 预约绑定说明。

安装前先检查 `~/.codex/skills/multi-agent-management` 是否已存在。已有安装应先比较差异并备份；按本次授权更新脚本与说明，保留本机 `config` 中的账号映射和个人策略。首次安装可将本目录放到上述位置，再重新打开 Codex 使 Skill 被识别。

公开包的 `config` 仅含停用的虚构示例，不能直接派单。实际映射由 Next 在自己的 Application Support 目录生成；必须重新核对身份、额度、Hub 路由及授权。不要把本机映射、私人主机地址或凭据提交到仓库。

先阅读 `SKILL.md`，再按 `references/coordination.md` 执行预约、预检、运行、验收与释放。所有时间窗只影响新派单，不阻止额度刷新和暖号。终端退出码为 0 仅证明会话结束，仍需核对实际产物。

Next、Hub 和 Skill 需要分别部署对应版本。仅安装此包不会更新应用或 Hub；旧入口也不会自动获得共享占用保障。原生终端使用私有启动回执，任务状态无法确认时保留占用，不自动认定为空闲。
